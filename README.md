# UniSkill

UniSkill is the autonomous skill manager, dynamic convergence engine, and token economizer for the Antigravity AI development ecosystem.

## Key Features
- Dynamic 100% Convergence Gate: Closes prompt gaps on-the-fly and aligns skills with modern standards.
- Token Economizer: Extracts blueprints and constitutional invariants, achieving up to 88% token reduction.
- Multi-Skill Composer: Merges complementary skills with dependency deduplication under token limits.
- Triple-Environment Sync: Enforces 100% SHA-256 bit-parity across all runtime configurations.
- Empirical Reliability: Tracks test and compiler execution outcomes in SQLite.
- System Diagnostic: Holistic verification across daemons, inotify capacity, and MCP protocols.

## Installation
```bash
cd uniskill
pip install -e .
```

## Basic Usage
```bash
# Check status and health
uniskill status
uniskill doctor

# Token economizing
uniskill extract camera1-to-camerax --blueprint-only
uniskill extract camera1-to-camerax --invariants-only

# Dynamic convergence
uniskill ensure "Barcode scanning with CameraX" --skill camera1-to-camerax

# Multi-skill composition
uniskill compose edge-to-edge camera1-to-camerax --max-tokens 2500
```

## Invariants
UniSkill strictly enforces zero shortcuts (Law-000), YAML 1.2 frontmatter formatting, and standard technical terminology across all registered skills.
